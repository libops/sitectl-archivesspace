# sitectl-archivesspace

A [sitectl](https://sitectl.libops.io) plugin for ArchivesSpace utilities. It works with the [LibOps ArchivesSpace template](https://github.com/libops/archivesspace).

The docs are available at [https://sitectl.libops.io/plugins/archivesspace](https://sitectl.libops.io/plugins/archivesspace).
